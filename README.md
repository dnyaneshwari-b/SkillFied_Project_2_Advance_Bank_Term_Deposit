# SkillFied Project 2 – Advance Bank Term Deposit

## Project Overview

This project analyzes customer data to understand factors associated with term deposit subscription.

## Dataset

- Total records: 41,188
- Total variables: 21
- Missing values: None

## Analysis Performed

- Customer age distribution
- Customer job distribution
- Average contact duration by deposit subscription
- Contact method analysis
- Number of campaign contacts vs deposit subscription
- Correlation heatmap
- Logistic Regression
- Feature importance analysis

## Machine Learning

A Logistic Regression model was developed to predict whether a customer subscribed to a term deposit.

**Model Accuracy: 91.43%**

## Key Findings

The analysis identified several influential variables associated with term deposit subscription, including:

- Contact method
- Consumer price index
- Employment variation rate
- Default status
- Previous campaign outcome
